Names, descriptions, pictures and gameplay videos for your games from ScreenScraper, fetched by the console itself.

Copy `Scraper-<version>.zip` to the `apps` folder of the console's HOME and install it in the App Installer. It needs the internet on the console (the USB cable in Network mode, with the PC's or a phone's connection shared with it) and a free ScreenScraper account. See the README for how to use it.
